# Learnings

> Frontend Kit memory. Corrections, gotchas and decisions captured during sessions, so
> they do not have to be rediscovered. Appended to by the `kit-self-improve` skill.
> Loaded at session start. Commit this file.

Format for each entry:

```
### YYYY-MM-DD — short title
**What happened:** the correction or discovery.
**Rule going forward:** the imperative version.
**Why:** the reason, so a future session knows when it stops applying.
```

Keep entries durable and project-specific. Prune anything that has become wrong — a
stale rule is worse than no rule. Past ~50 entries, consolidate the durable ones into
`conventions.md`.
